## 3. 实际模型流程

1. 每个场景缓存冻结 SSR 的 `scene_query [16,256]`。
2. SSR token 查询 36 个 DINOv2 外观 token。外观 token 包含 768 维内容、
   车辆坐标锚点和有效性 mask，得到外观更新后的 `S1`。
3. 两通道 SAM3 派生语义图经过三层 stride-2 CNN，形成 1035 个稠密语义
   token。位置来自同一车辆坐标网格的自适应池化。
4. `S1` 查询稠密语义 token，得到 `S2`。因此语义分支不是并行查询 `S0`。
5. `S2` 均值池化后进入 `256-256-36` MLP，输出 3 个命令分支，每个分支
   包含 6 个二维路径点。
6. 训练只对当前路线对应的命令分支计算 L1 loss。
7. SSR、DINOv2 和 SAM3 输出固定；两条融合分支与 waypoint head 联合训练。

模型共有 523,300 个可训练参数。公开版与归档模型的 state-dict 键、初始化
顺序和真实输入前向结果已经逐元素核验一致。

PnP gate 的实现为 `clip((10 - RMS_px) / 5, 0, 1)`。它是固定的场景级可靠性
缩放，不是论文的主要创新点，正文只需简要说明。

## 4. 当前正式结果

正式评估包含 97 个实体场景、181 条路线、5 折和 3 个随机种子，共 15 次
训练。主结果是对每条路线的三个 held-out 预测先求平均，再计算误差，不是
三个单模型指标的算术平均。

| 子集 | M0 ADE/FDE | AERIAL-LF ADE/FDE |
| --- | ---: | ---: |
| 全部 | 47.593 / 95.356 mm | 36.108 / 69.578 mm |
| 右转 | 62.128 / 138.098 mm | 42.308 / 84.457 mm |
| 直行 | 27.946 / 36.856 mm | 21.853 / 33.487 mm |
| 左转 | 38.495 / 69.530 mm | 39.757 / 80.747 mm |

整体 ADE/FDE 分别下降 24.1% 和 27.0%。181 条路线中，130 条 ADE 更低，
113 条 FDE 更低；92 条右转路线中，71 条 FDE 更低。三个单 seed 的均值为
39.891 +/- 0.311 mm ADE 和 72.778 +/- 1.259 mm FDE。

## 7. 投稿前最重要的实验缺口

### P0：训练预算匹配的车辆侧对照

当前 AERIAL-LF 从 M0 head 初始化后继续联合训练 50 epochs，而 M0 没有相同
时长的 continuation。最有说服力的对照是：保持相同初始化、优化器、head
学习率、epoch 和 checkpoint selection，仅关闭 aerial residual。该实验决定
24.1%/27.0% 中有多少可以归因于空中输入，而不是额外 head 优化。

### P0：blocked/clear 成对响应指标

论文最有辨识度的故事不是普通 ADE，而是地面不可见、UAV 可见的下游障碍
是否让末端路线发生合理变化。需要建立经过审核的 pair ledger，并报告终点
横向偏移、障碍走廊冲突率、正确区域进入率以及 pair-level bootstrap 区间。
不能用“右转 FDE 更低 71/92”代替这项因果更明确的证据。

### P1：同条件消融

至少需要 vehicle only、appearance only、semantics only、appearance+semantics、
去掉位置编码、交换融合顺序等同输入同训练预算实验。gate 可以只做附属消融，
不值得占据主叙事。

### P1：独立测试集

当前五折能验证 held-out 场景，但同一个沙盘语义和道路风格仍反复出现。扩充
数据后应锁定一批从未用于模型选择的新场景，最好包含新的 UAV 悬停位置、
遮挡物组合和路口布局。

## 8. 当前架构最值得改进的逻辑点

1. **命令进入得太晚。** 目前 attention 在三个命令间完全共享，命令只在最终
   head 分支选择时起作用。左转退化说明可以优先测试 command embedding、
   command token 或 FiLM，使 UAV 检索围绕当前路线意图发生。
2. **全无效 token 仍可能产生偏置。** 两个分支在所有 token 无效时，attention
   context 会被置零，但训练后的 output bias 仍可能产生 residual。后续版本应
   用 branch-availability mask 再乘一次最终 residual，保证无有效 aerial evidence
   时严格不更新 latent。
3. **两条残差初始化不对称。** DINO output projection 为零初始化，semantic
   output projection 使用默认初始化。更稳定的比较是两条分支都零初始化，或
   使用可学习且从零开始的 residual scale。
4. **场景级 gate 过粗。** 同一个 PnP RMS 同时缩放所有 appearance 和 semantic
   token，不能表达局部遮挡、投影外区域或不同 token 的定位不确定性。后续可
   测试 token-level geometric confidence，但不应把它作为当前论文主贡献。
5. **双重位置编码需要消融。** 缓存 DINO token 已加入幅度 0.01 的固定正弦位置
   编码，F15 又加入 learned anchor MLP。二者可能互补，也可能重复，必须通过
   同条件消融判断。
6. **简单均值池化限制路线选择。** 16 个 SSR token 最后直接均值池化，可能
   稀释与转向出口相关的 token。command-conditioned attention pooling 是比单纯
   加深 MLP 更有针对性的升级。
7. **输出约束只保证前向单调。** 当前 head 不显式约束曲率、道路边界或障碍
   间距。后续可以加入轻量 corridor/collision auxiliary loss，但必须使用独立
   GT 或几何标签，不能让 SAM3 输入同时成为未经控制的监督答案。

上述架构修改都应作为新版本实验，不应回写或覆盖当前 F15 归档结果。
